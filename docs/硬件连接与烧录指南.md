# 硬件连接与烧录指南

## 1. 所需材料

| 材料 | 数量 | 说明 |
|------|------|------|
| STM32F103C8T6 最小系统板 | 1 | Blue Pill |
| USB 转 TTL 串口模块 | 1 | CH340 或 CP2102 |
| SSD1306 OLED 0.96寸 | 1 | I2C 接口，128×64（可选） |
| ST-Link V2 调试器 | 1 | 烧录调试（可选，也可用串口烧录） |
| 电阻 1kΩ | 1 | 限流保护 |
| 电容 100nF | 1 | RC 低通滤波 |
| 杜邦线 | 若干 | 至少 8 根 |
| 面包板 | 1 | 方便接线（可选） |

## 2. 引脚分配

```
                    ┌─────────────────────┐
                    │    STM32F103C8T6    │
                    │     Blue Pill       │
        ┌───────────┤                     ├───────────┐
        │ 3.3V      │                     │      GND  │
        │ NRST      │                     │      3.3V │
        │ PA0  ←────│── ADC 输入          │      PA15 │
        │ PA6  ────→│── PWM 输出          │      PB6  │── I2C SCL (OLED)
        │ PA9  ────→│── USART1_TX         │      PB7  │── I2C SDA (OLED)
        │ PA10 ←────│── USART1_RX         │      PB9  │── 按键(波形切换)
        │ PA13(SWDIO)│                    │      PC13 │── 板载LED
        │ PA14(SWCLK)│                    │           │
        └───────────┤                     ├───────────┘
```

## 3. 接线步骤

### 3.1 信号回环（PA6 → PA0）

```
  PA6 ──[1kΩ 电阻]──┬── PA0
                    │
                 [100nF 电容]
                    │
                   GND

调试阶段可只接电阻不接电容，波形会有 PWM 纹波但能验证基本功能。
```

### 3.2 串口连接

```
STM32              USB转串口模块
PA9  (TX) ───────→ RXD
PA10 (RX) ←─────── TXD
GND       ─────── GND     ← 必须共地！

注意: TX→RX 交叉连接，VCC 不接
```

### 3.3 OLED 连接（可选）

```
STM32              SSD1306
PB6 (SCL) ─────── SCL
PB7 (SDA) ─────── SDA
3.3V      ─────── VCC
GND       ─────── GND
```

### 3.4 ST-Link 连接（烧录用）

```
ST-Link V2          STM32
SWDIO ──────────── PA13
SWCLK ──────────── PA14
GND   ─────────── GND
3.3V  ─────────── 3.3V
```

### 3.5 完整接线总图

```
                        ┌─────────────────────┐
                        │    STM32F103C8T6    │
                        │                     │
  ST-Link 3.3V ─────────│─ 3.3V               │
  ST-Link GND  ─────────│─ GND                │
  ST-Link SWDIO─────────│─ PA13               │
  ST-Link SWCLK─────────│─ PA14               │
                        │                     │
                        │ PA0 ←──────┬────────│── [1kΩ] ── PA6
                        │            │        │
                        │         [100nF]     │
                        │            │        │
                        │           GND       │
                        │                     │
                        │ PA9  ──────────────→│── 串口 RXD
                        │ PA10 ←──────────────│── 串口 TXD
                        │ GND  ──────────────→│── 串口 GND
                        │                     │
                        │ PB6  ──────────────→│── OLED SCL
                        │ PB7  ──────────────→│── OLED SDA
                        │                     │
                        └─────────────────────┘
```

## 4. 烧录方法

### 4.1 ST-Link 烧录（推荐）

1. 安装 [ST-Link 驱动](https://www.st.com/en/development-tools/stsw-link009.html)
2. 连接 ST-Link 到 STM32（4 根线：SWDIO, SWCLK, GND, 3.3V）
3. VSCode 打开 `firmware/` 目录
4. `platformio.ini` 中设置 `upload_protocol = stlink`
5. 编译烧录：

```bash
pio run --target upload
```

### 4.2 串口烧录（无 ST-Link 时）

1. 将 **BOOT0 接 3.3V**，BOOT1 接 GND，按复位键进入 ISP 模式
2. 修改 `platformio.ini`：

```ini
upload_protocol = serial
upload_port = COMx    ; 改成你的实际串口号
```

3. 执行烧录
4. 烧录完成后将 **BOOT0 接回 GND**，按复位键正常运行

### 4.3 查找串口号

- 设备管理器 → 端口(COM和LPT) → 找到 CH340 对应的 COM 号
- 或在 VSCode 底部 PlatformIO → Devices 标签查看

## 5. 上位机运行

```bash
# 安装 Python 3.9+
# 安装依赖
cd pc_app
pip install -r requirements.txt

# 运行
python oscilloscope_pc.py
```

操作步骤：
1. 确保 MCU 已烧录并上电
2. USB 转串口已连接电脑
3. 上位机中选择正确串口号
4. 点击"连接设备"
5. 点击"开始"
6. 查看实时波形

## 6. 常见问题

### LED 快闪（约 5Hz）

Error_Handler 被调用，外设初始化失败。检查板子是否有 8MHz 晶振、电源是否稳定。

### 烧录失败 "No device found"

检查 ST-Link 4 根线连接、STM32 是否上电、驱动是否安装。

### 上位机看不到波形

- PA6 和 PA0 之间是否接了 1kΩ 电阻？
- 串口 TX→RX 是否交叉连接？
- GND 是否共地？
- 串口号和波特率（460800）是否正确？
- 是否点击了"连接"和"开始"？

### 波形失真

增大滤波电容（如换 1μF），或降低输出频率（100Hz 效果最好）。

### OLED 不显示

检查 I2C 接线，确认 OLED 地址为 0x3C。固件会自动检测 I2C 总线是否有上拉电阻，未检测到则跳过 OLED。

## 7. 快速开始清单

```
□ 1. 安装 VSCode + PlatformIO 插件
□ 2. 连接 ST-Link → STM32（SWDIO, SWCLK, GND, 3.3V）
□ 3. VSCode 打开 firmware/ → Upload 烧录
□ 4. 接线: PA6 →[1kΩ]→ PA0，串口 TX/RX 交叉连接
□ 5. (可选) 接 OLED: PB6→SCL, PB7→SDA
□ 6. USB转串口插电脑
□ 7. cd pc_app && pip install -r requirements.txt
□ 8. python oscilloscope_pc.py
□ 9. 选串口 → 连接 → 开始 → 看到波形！
```
